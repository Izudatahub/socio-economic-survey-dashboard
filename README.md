Project Overview

This project demonstrates how data visualization can communicate a community's socio-economic profile through charts, KPI cards, filters, and multi-page navigation.

The dashboard explores demographic characteristics, educational attainment, occupation, income distribution, infrastructure access, health status, and perceived community challenges.

Dataset

The repository includes "simulated-community-socioeconomic-data.csv", a synthetic dataset containing 1,250 illustrative records.

The dataset includes age group, education level, literacy, occupation, employment status, income, electricity access, water source, toilet facility, health status, and community challenges.

The dataset is intended for learning and demonstration. It must not be interpreted as verified findings from an actual community survey.

Key Questions

- Which age groups are most represented?
- What are the education and literacy patterns?
- Which occupations and income categories are most common?
- How do respondents access electricity, water, and sanitation?
- How is health status distributed?
- What are the most frequently reported community challenges?

How to Use

1. Download the CSV dataset from this repository.
2. Open it in Microsoft Excel or import it into Power BI.
3. Review the dashboard screenshots.
4. Use the dataset for practice, analysis, and visualization exercises.

Limitations

- The dataset is simulated, not collected from actual respondents.
- Individual-level records are illustrative.
- Dashboard percentages and category counts may use different definitions or denominators. Verify the calculations before drawing conclusions.
