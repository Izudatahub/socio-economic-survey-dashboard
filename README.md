# Socio-Economic Survey Dashboard

An interactive, three-page dashboard exploring a **simulated community socio-economic dataset**. The project presents a high-level view of respondents' demographics, education, employment, income, access to basic infrastructure, health status, and perceived community challenges.

> **Data note:** This project uses simulated data for portfolio and demonstration purposes. The figures do not represent a verified survey of a real community.

## Key Questions Explored

- What age groups are most represented among respondents?
- What are the respondents' education and literacy profiles?
- Which occupations and income sources are most common?
- How do respondents access electricity, water, and sanitation?
- How are employment and health statuses distributed?
- Which community challenges receive the most responses?
